# Camprover Level Final

Kullanıcının kendi Discovery 2 fotoğrafları kullanıldı:
- Pitch: arka görünüş fotoğrafı
- Roll: yan görünüş fotoğrafı

Özellikler:
- Pitch/Roll tam derece
- ±0.5° içinde ilgili çerçeve kalınlaşır: Pitch yeşil, Roll kırmızı
- Pozitif/negatif yazıları yok
- Araç görselleri eğime göre hareket eder
- Ortada ±10° dairesel su terazisi ve hareket eden hava kabarcığı
- Başlangıçta ZERO yok
- Safari/PWA uyumlu

iPhone Safari sensör erişimi için HTTPS gerekir.
